# مواد الاجتماع مع مدرسة

- `brochure.pdf`: ورقة تعريف بصفحة واحدة (A4) تعطيها للمدرسة. بلا أسعار ولا وعود، وتفصل بين "جاهز اليوم" و"قادم".
- `questions.pdf`: أسئلة الاجتماع (صفحتان) لتفهم المدرسة قبل أن تعرض: من هم، كيف يعملون، التقنية، المال، القرار والخصوصية، التجربة.
- المصدر: `brochure.html` و`questions.html`؛ عدّل النص ثم `node make-pdf.js` (يحتاج `npm i playwright`). الصور من `docs/guide/img`.
