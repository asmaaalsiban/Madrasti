# سيناريو عرض مدرستي على مدرسة (15 دقيقة)

**قبل العرض:** شغّل نسخة التجربة (انظر `README.md` لحسابات التجربة). ابدأ من متصفحين أو نافذتين: واحدة للمدير والأخرى بحجم جوال لولي الأمر.

| الدقيقة | ماذا تعرض | لماذا يهم المدرسة |
|---|---|---|
| 0-1 | الصفحة الأولى (شعار المدرسة واسمها) ثم الدخول | تبدو المدرسة مالكة المنصة (علامتها). |
| 1-3 | **المدير: نظرة عامة** وقائمته، ثم زر **ترتيب** (غيّر حجم الأيقونات ولونها) | كل شخص يرتب شاشته. |
| 3-5 | **المعلم:** تسجيل الحضور، التحضير، العلامات، ثم **راتبي**: الدائرة تظهر الخصم بسبب الغياب | الحضور مربوط بالراتب تلقائياً. |
| 5-7 | **المدير:** المهام (وزّع مهمة على معلمين وأرفق ملفاً)، ثم **ماذا يرى الموظفون** | متابعة الكادر وإخفاء ما لا يلزم. |
| 7-9 | **المدير:** الجدول، الامتحانات (مراقب واحد لكل قاعة بلا تعارض)، المناوبات | يوفّر ساعات عمل يدوي. |
| 9-12 | **ولي الأمر (جوال):** الرئيسية، العلامات، المواصلات، **الرسوم** ← **الدفع** (بطاقة أو تحويل بنكي مع صورة) | تجربة الأهل: بسيطة ومباشرة. |
| 12-13 | **المحاسب:** **التحويلات البنكية**: راجع الإثبات واضغط "وصل المبلغ"؛ ثم يرى الأب السند | المحاسب يتحكم، لا تُسجَّل دفعة قبل تأكيده. |
| 13-14 | **أخبار الصف** والإعلانات والمحادثات (أيقونات الأعلى) | تواصل المدرسة مع الأسرة في مكان واحد. |
| 14-15 | **الخصوصية:** موافقة الأهل على الصور، تنزيل نسخة البيانات، طلبات الحذف؛ وسجل التدقيق | حماية بيانات الأطفال. |

## أسئلة متوقعة وأجوبة صادقة
- **كم تكلفة الاشتراك؟** قرار تجاري عندكم؛ لا يوجد رقم في النظام. 
- **أين تُحفظ بياناتنا؟** في قاعدة بيانات منفصلة لمدرستكم على سيرفر المنصة، مع نسخ احتياطي ليلي. 
- **هل نستطيع الدفع ببنكنا؟** التحويل البنكي/كليك جاهز. أما بوابة بنكية محددة فنحتاج توثيقها التقني لنضيفها. 
- **واتساب؟** غير جاهز بعد (يحتاج حساب WhatsApp Business). 
- **هل يعمل على الجوال؟** نعم عبر المتصفح (ويمكن تثبيته كتطبيق)؛ لا يوجد تطبيق أصلي (native) حالياً. 
- **أمان الأطفال؟** بيانات كل مدرسة معزولة، وكل دور يرى ما يخصه فقط، وسجل تدقيق، وموافقة الأهل على الصور. النصوص القانونية قيد مراجعة محامٍ.
