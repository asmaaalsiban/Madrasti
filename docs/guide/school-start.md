# تشغيل مدرسة جديدة خطوة بخطوة

لمن يجهّز مدرسة جديدة (فريق المنصة مع مدير المدرسة).

## أ) إنشاء المدرسة (فريق المنصة)
```bash
php artisan school:create school1 "مدرسة النور" --admin-name="أحمد" --admin-email=admin@school1.example --admin-password='كلمة-مرور-قوية' --color="#006ddb" --locale=ar
```
ينشئ قاعدة بيانات المدرسة وجداولها والإعدادات الأولى والمدير الأول. **رمز المدرسة** (`school1`) هو ما يكتبه المستخدمون للدخول. ثم سلّم المدير الرابط ورمز المدرسة وكلمة مروره (سيُطلب منه تغييرها).

## ب) إعداد المدرسة (المدير) بهذا الترتيب
1. **السنة الدراسية** والفصول (إعداد المدرسة ← السنوات الدراسية، الفصول). 
2. **الصفوف** (grade levels) والمواد، وما يُدرَّس في كل صف (المنهج). 
3. **الشعب**: يمكن توليدها دفعة واحدة لكل صف. 
4. **اليوم الدراسي**: الأيام وعدد الحصص ومدتها والاستراحات. 
5. **الكادر**: إضافة المعلمين والإداريين (أو **استيراد** من Excel)، مع نوع كل وظيفة ومادة المعلم وصفوفه. تُنشأ لهم حسابات؛ سلّمهم بيانات الدخول. 
6. **الطلاب**: استيراد من Excel (الاسم، رقم الطالب، الصف/الشعبة، بريد أو هاتف ولي الأمر). يُنشأ لكل أسرة حساب ولي أمر وحساب للطالب. 
7. **توزيع المعلمين على الشعب** ثم **توليد الجدول** (بلا تعارض)، وجدول الامتحانات والمناوبات لاحقاً. 
8. **المالية** (المحاسب): هيكل الرسوم لكل صف وخطة الأقساط، والعملة، وطرق الدفع (بطاقة PayTabs بمفاتيح المدرسة، وتحويل بنكي/كليك).
9. **الرواتب** (المحاسب): العقود وقواعد الخصم والمكافأة.
10. **الأهل**: أرسل لهم رابط المدرسة ورمزها وبيانات الدخول؛ اطلب منهم من **الخصوصية وبياناتي** السماح أو عدمه بنشر صور أبنائهم، ثم اضبط سياسة الصور (الموصى بها: *بموافقة فقط*).

## ج) قبل الإطلاق
- [ ] مراجعة **سياسة الخصوصية وشروط الاستخدام** مع محامٍ، وتعبئة بيانات الجهة (`VITE_COMPANY_*`) وإخفاء تنبيه "مسودة". 
- [ ] **عقد معالجة بيانات** موقّع مع المدرسة. 
- [ ] تجربة PayTabs بحساب تجريبي وبطاقة تجريبية قبل الحساب الحقيقي. 
- [ ] إعداد **البريد** (`MAIL_*`) لإعادة كلمة المرور. 
- [ ] **النسخ الاحتياطي** (يعمل ليلاً تلقائياً: `php artisan backup:status`)، مع نسخة خارج السيرفر. 
- [ ] على السيرفر: `php artisan optimize` عند كل نشر، وتفعيل OPcache. انظر `loadtest/README.md`. 
- [ ] فحص الوصول: `a11y/axe-check.js`. 

## د) في الأسبوع الأول
- مرّن المعلمين على **التحضير** و**ملخص الحصة** و**العلامات** (نصف ساعة تكفي). 
- راقب **طلبات البيانات** و**التحويلات البنكية** يومياً. 
- اجمع ملاحظات المعلمين والأهل وسجّلها لتحسين النسخة التالية.
