# دليل الطالب

![الرئيسية](img/student-home.png)

- **الجدول**: حصصك للأسبوع. 
- **الواجبات**: اقرأ الواجب وأرسل إجابتك (نص أو صور). 
- **العلامات والنقاط والشارات**: تظهر في الصفحة الرئيسية. 
- **الامتحانات**: مواعيدك وقاعتك. 
- **أخبار الصف** (الأيقونة بالأعلى) والإعلانات والمحادثات.
