## 4. الجدول الكامل للأدمن (طلبك الأهم)

**الفكرة:** نفس الورقة التي يحبونها في Excel، لكن حيّة.

```
        │ الأحد                                   │ الإثنين …
شعبة →  │ ح1       ح2       ح3 … ح7              │ ح1 …
ثامن أ  │ علوم·ه   إنجليزي·ف  عربي·أ …            │
ثامن ب  │ …
تاسع أ  │ …
…
المناوبة │ 4 أسماء لكل يوم
```

- **الصفوف = الشعب، الأعمدة = اليوم × الحصة** (مثل ورقتهم، أو تبديل المحور).
- كل خانة: المادة + اسم المعلم، بلون لكل مادة.
- **تعارض = خانة حمراء** مع سبب ("المعلم مسجّل في 9أ و10ج").
- فلاتر: الصف، اليوم، مادة، معلم، "إظهار التعارضات فقط".
- **تبديل المحور**: كل المعلمين كأعمدة، فتعرف **من المتفرغ الآن**.
- الضغط على خانة يفتح تعديلها (موجود عندنا)، مع منع التعارض.
- **تصدير Excel** بالشكل الأصلي، و**طباعة/PDF** (A3 أفقي) بنموذج الوزارة وخانات التوقيع.
- المعلم يبقى يرى جدوله فقط؛ الأدمن (والمديرة) هما من يرى الكل. صلاحية قراءة للمساعدة والمرشدة اختيارية.
- أنصح بنسختين: "مسودة" و"منشور"، والمعلمون يرون المنشور فقط.

## 5. حدود هذا التحليل

- لا أعرف إن كانت الورقة "(2)" فرعًا ثانيًا أم نسخة بديلة. الأرجح بحسب الرأس "أم الدنانير" فرع، لكن تطابق 557 خانة (يوم، حصة، اسم) بين الورقتين يوحي بنسخة من الجدول نفسه.
- مطابقة الأسماء بالأسماء الأولى تقديرية؛ أرقام الأحمال لكل معلم (14 من 44 تختلف عن النصاب المعلن) غير موثوقة لهذا السبب.
- بعض "التعارضات" قد تكون دروسًا مشتركة مقصودة. لا أعرف قواعد المدرسة.
- لم أر نموذج الوزارة الأصلي، فقط نسخة Excel منه.
